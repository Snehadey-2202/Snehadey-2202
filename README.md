## 🔬 Ongoing Project

### 🛡️ Deep Packet Inspector *(In Progress)*
> A low-level network analysis tool for real-time packet capture and protocol dissection

Building a deep packet inspection (DPI) engine in C++ that captures live network traffic, dissects protocol headers (Ethernet, IP, TCP/UDP), and analyses packet payloads in real time. The tool aims to provide visibility into network flows, detect anomalies, and lay the groundwork for more advanced intrusion detection capabilities.

**Highlights:**
- 🔌 Raw socket programming for live packet capture
- 📦 Protocol dissection across Ethernet, IPv4/IPv6, TCP, UDP, and ICMP layers
- 📊 Real-time traffic statistics and flow tracking
- 🔍 Payload inspection with pattern matching support
- ⚡ High-performance design using efficient memory and buffer management

**Stack:** C++ · Raw Sockets · libpcap · Linux Networking

> 🚧 *Currently in active development — stay tuned!*
